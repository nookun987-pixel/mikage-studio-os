# MIKAGE CANON CONFLICTS

## **Character State vs Narrative Freedom**

### **1. Loyalty Vector vs Plot Requirements**
- **Conflict**: Character State Tracker defines loyalty as conditional vector, but some narrative packs require binary loyalty for plot simplicity
- **Files Involved**: 
  - `MIKAGE — CHARACTER STATE TRACKER PACK.md` (Law 7: loyalty is conditional)
  - Various narrative template packs (simplified loyalty models)
- **Resolution Required**: Define when conditional vs binary loyalty models apply
- **Impact**: High - Affects character motivation and plot development

### **2. Damage Persistence vs Scene Reset**
- **Conflict**: Some packs allow damage to heal between scenes, others require persistent damage tracking
- **Files Involved**:
  - Character State Tracker (Law 3: persistence matters)
  - Various scene template packs (reset-friendly damage models)
- **Resolution Required**: Clear rules for damage persistence vs narrative convenience
- **Impact**: Medium - Affects character continuity and visual consistency
