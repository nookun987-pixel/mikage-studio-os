# MIKAGE STUDIO WORKFLOW

This workflow defines how Mikage visual experiments are executed.

Every batch must follow this process.

---

# STEP 1 — CHIEF PLAN

Define:

objective  
visual direction  
mode strategy

Chief must run all three modes.

---

# STEP 2 — COMPILE PROMPTS

Create prompt sets for:

canon_core  
luminous_fan_appeal  
luxury_mystical_editorial

Each set must include:

positive prompt  
negative prompt  
sampler  
steps  
cfg  
seed policy

---

# STEP 3 — GENERATE IMAGES

Run image generation for all modes.

Store:

asset URL  
generation parameters  
timestamp

---

# STEP 4 — REVIEW

Score each image using 5 dimensions.

1 soul fidelity  
2 visual attraction  
3 luxury editorial feel  
4 usable asset strength  
5 canon potential

Score range: 1–10.

---

# STEP 5 — CANON GATE

Classify the result.

Possible labels:

reject  
interesting_but_non_canon  
usable_asset  
canon_candidate

---

# STEP 6 — ARCHIVE

Record full run data.

Archive must include:

objective  
modes tested  
prompt sets  
parameters  
outputs  
scores  
classification  
winner  
failure notes  
next adjustment

---

# STEP 7 — NEXT RUN DECISION

Chief determines:

winning mode  
mode to refine  
mode to drop

Then prepares next batch.

---

# BATCH SUCCESS RULE

A batch is valid only if:

three modes generated  
review completed  
canon classification assigned  
archive entry created

Otherwise the batch must be rerun.
