# MIKAGE ZENITH — PROJECT MASTER

This file defines the **visual identity, canon rules, and prompt system** for the Mikage Zenith project.

---

# CHARACTER CORE

Mikage is defined by:

- calm introspective presence
- minimal emotion
- strong visual gravity
- porcelain-like elegance
- restrained futuristic aesthetic

Mikage must never appear as:

- childish anime character
- exaggerated idol caricature
- cartoonish fantasy figure

---

# VISUAL PHILOSOPHY

The visual direction blends:

Japanese minimalism  
hard sci-fi elegance  
high-fashion editorial mood

The aesthetic must feel:

refined  
controlled  
mysterious  
luxurious

---

# THREE VISUAL MODES

All test runs must generate **three modes**.

---

## MODE 1 — CANON CORE

Purpose:

baseline character representation

Characteristics:

clean portrait  
soft lighting  
minimal composition  
editorial simplicity

Use cases:

lore illustration  
reference images

---

## MODE 2 — LUMINOUS FAN APPEAL

Purpose:

fan attraction and social appeal

Characteristics:

radiant lighting  
strong eye contact  
vivid color accents

Use cases:

posters  
social media visuals

---

## MODE 3 — LUXURY MYSTICAL EDITORIAL

Purpose:

high-fashion campaign visuals

Characteristics:

dramatic lighting  
dark palette  
mystical elegance

Use cases:

campaign visuals  
editorial spreads

---

# PROMPT PACK STRUCTURE

Each generation must include:

positive prompt  
negative prompt  
sampler  
steps  
cfg  
seed rule

---

# CANON INVARIANTS

Must always preserve:

character identity  
visual dignity  
lore constraints  
aesthetic consistency

---

# DRIFT WARNINGS

Reject outputs that show:

cheap fantasy styling  
generic anime idol look  
excessive visual clutter  
loss of Mikage identity

---

# ACCEPTABLE VARIATIONS

Allowed creative freedom:

materials  
lighting style  
fashion direction  
environment

But core identity must remain.

---

# PROJECT SUCCESS CONDITION

The project succeeds when:

a consistent Mikage visual language emerges  
high quality assets are archived  
a winning direction becomes clear
