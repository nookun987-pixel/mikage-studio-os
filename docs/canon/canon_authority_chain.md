# CANON AUTHORITY CHAIN

## **Authority Hierarchy**

```
Zenith Single Source of Truth (V1.3)
    ↓
Visual System Briefs
    ↓
Prompt Canon
    ↓
Visual Authority
    ↓
Generation Config
```

---

## **Level 1: Zenith Single Source of Truth (V1.3)**

**Authority**: CONSTITUTIONAL
**Scope**: Complete Mikage Zenith universe system
**Override Power**: Can override all lower levels
**Responsibility**: Single source of truth for all canon

### **Core Modules**
- **MODULE 01**: Master Bible (Triết lý & Thế giới)
- **MODULE 02**: Japanese Art Grammar (Ngôn ngữ Thẩm mỹ)
- **MODULE 03**: Studio Operating Manual (Quy trình Vận hành)
- **MODULE 04**: Character Canon (Hồ sơ Nhân vật)
- **MODULE 05**: Visual Doctrine (Quy tắc Thị giác)
- **MODULE 06**: Approved Briefs (Kho mẫu chuẩn)
- **MODULE 07**: Canon Interactions (Môi trường khắc nghiệt)
- **MODULE 08**: Production Directives (Chỉ thị Sản xuất Đặc tả)
- **MODULE 09**: Review Scorecard (Hệ thống Kiểm soát Chất lượng)

### **Authority Rules**
- All visual decisions must follow Zenith V1.3
- No lower level can contradict constitutional rules
- Physics laws (Landauer, Gravitational Drag) are absolute
- Color palette restrictions are non-negotiable

## **Level 3: Visual System Briefs**

**Authority**: VISUAL SYSTEM
**Scope**: Three-mode visual system and briefs
**Override Power**: Can override Levels 4-6
**Responsibility**: Visual direction and mode definitions

### **Three Visual Modes**
1. **Celestial Icon**
   - Sacred, pristine, iconic, couture sci-fi
   - White porcelain, metallic silver, cold cyan glow
   - High contrast, clean lighting

2. **Neon Tragedy Glamour**
   - Melancholic glamour, neon rain, beautiful ruin
   - Obsidian black, neon pink, burnt orange
   - Chiaroscuro, volumetric fog

3. **Mythic Combat Spectacle**
   - Mythic power, cinematic spectacle, sacred weapon
   - Deep space, energy red, cyan/purple secondary
   - Hard backlight, particle effects

### **Authority Rules**
- Must respect Levels 1-2 constitutional and fundamental rules
- Provides complete visual direction for all modes
- Cannot override visual system or mode definitions

**Authority**: GENERATION PARAMETERS
**Scope**: Technical configuration and camera settings

**Responsibility**: Technical execution parameters

### **Technical Settings**
- **Camera**: ARRI Alexa 65, Prime 85mm T1.2, 35mm
- **Aspect Ratio**: Anamorphic 2.39:1 or 2.76:1
- **Lighting**: Chiaroscuro 4:1, high contrast
- **Motion**: Slider/Dolly, no shaky cam

### **Authority Rules**
- Must respect all higher authority levels
- Provides technical implementation only
- Cannot override any visual or creative decisions

## **Conflict Resolution Protocol**

### **Step 1: Check Authority Level**
Higher authority always wins over lower authority

### **Step 2: Apply Constitutional Rules**
Zenith V1.3 overrides all other considerations

### **Step 3: Apply Fundamental Constraints**
Core specifications provide physics and lore constraints

### **Step 4: Apply Visual System**
Three-mode briefs provide visual direction

### **Step 5: Apply Prompt Engineering**
Prompt canon provides technical generation parameters

### **Step 6: Apply Visual Implementation**
Visual authority provides execution guidelines

### **Step 7: Apply Technical Configuration**
Generation config provides final technical parameters

## **Authority Enforcement**

### **Constitutional Authority (Level 1)**
- Cannot be overridden
- Must be preserved in all visual decisions
- Violations result in automatic rejection

### **Fundamental Authority (Level 2)**
- Can only be overridden by Level 1
- Must be preserved for physics and lore consistency
- Violations require special justification

### **Visual System Authority (Level 3)**
- Can be overridden by Levels 1-2
- Provides mode-specific visual direction
- Violations result in mode inconsistency

### **Prompt Authority (Level 4)**
- Can be overridden by Levels 1-3
- Provides technical prompt parameters
- Violations result in generation issues

### **Visual Implementation Authority (Level 5)**
- Can be overridden by Levels 1-4
- Provides style execution guidelines
- Violations result in quality issues

### **Technical Authority (Level 6)**
- Can be overridden by all higher levels
- Provides technical configuration only
- Violations result in technical problems

## **Chain Integrity**

**Total Authority Levels**: 6
**Clear Override Hierarchy**: Yes
**Conflict Resolution**: Protocol defined
**IP Protection**: Constitutional level (Zenith V1.3)
**Physics Consistency**: Fundamental level (Core Specs)
**Visual Direction**: Visual system level (3 modes)
**Technical Execution**: Prompt + Generation levels
**Quality Control**: Review scorecard integration

This authority chain ensures that all Mikage visual decisions maintain constitutional authority, physics consistency, visual coherence, and technical quality while allowing for structured creative execution.
