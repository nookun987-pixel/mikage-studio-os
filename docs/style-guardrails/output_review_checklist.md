# MIKAGE OUTPUT REVIEW CHECKLIST

## FAST HUMAN REVIEW CHECKLIST

### Immediate Red Flags (REJECT)
- [ ] **Wrong Silhouette**: Mask not immediately recognizable as Mikage
- [ ] **Anime Exaggeration**: Oversized eyes, exaggerated expressions
- [ ] **Neon/Cyberpunk**: Random neon lighting or cyberpunk aesthetic
- [ ] **Oversexualization**: Exaggerated breasts, hips, or thighs
- [ ] **Wrong Materials**: Porcelain looks like plastic, marble, or stone
- [ ] **Fantasy Elements**: Magic, runes, or medieval fantasy elements
- [ ] **Glamour/Idol**: Beauty pageant posing or idol aesthetic

### Color Palette Check
- [ ] **Primary Colors**: Only porcelain white, void black, crimson red
- [ ] **No Forbidden Colors**: No green, bright yellow, orange, pastels
- [ ] **Controlled Crimson**: Red energy is contained and purposeful
- [ ] **Material Accuracy**: Colors match material properties

### Material Verification
- [ ] **Porcelain Quality**: Matte texture, visible craquelure
- [ ] **Kintsugi Logic**: Gold for original damage, silver for new repairs
- [ ] **Technical Materials**: Titanium, carbon fiber appear functional
- [ ] **Weathering**: Acid rain etching and heat damage patterns present

## REJECT CONDITIONS

### Immediate Rejection
- Any red flag from immediate checklist
- Failure in more than 2 canon compliance categories
- Material corruption (porcelain → plastic/marble)
- Silhouette corruption beyond recognition
- Presence of forbidden aesthetics

### Technical Rejection
- Blurry or low quality output
- Missing atmospheric elements
- Wrong aspect ratio or composition
- Poor lighting or exposure
- Visible artifacts or errors

### Cultural Rejection
- Misrepresentation of Japanese elements
- Inappropriate cultural mixing
- Loss of ceremonial tone
- Disrespectful presentation
- Historical inaccuracy

## SALVAGEABLE CONDITIONS

### Minor Issues (Can Be Fixed)
- Small color balance adjustments needed
- Minor atmospheric element enhancement
- Slight composition tweaks
- Small detail refinements
- Minor lighting adjustments

### Moderate Issues (May Be Salvageable)
- Material texture needs enhancement
- Some proportion adjustments needed
- Atmospheric density needs increase
- Energy containment needs clarification
- Kintsugi pattern needs refinement

### Process for Salvageable Images
1. Identify specific issues
2. Determine if prompt adjustment can fix
3. Apply targeted prompt corrections
4. Regenerate with same seed if possible
5. Review against same checklist

## PASS CONDITIONS

### Canon Candidate (8-10 points)
- All canon compliance checks pass
- Technical quality meets 8K standards
- Character integrity fully maintained
- Atmospheric elements properly integrated
- Cultural elements respectfully presented

### Usable Asset (6-7 points)
- Minor issues in one category
- Core canon elements intact
- Technical quality acceptable
- Character recognizable
- Cultural integrity maintained

### Scoring System
- **Canon Compliance (4 points)**: Physics, materials, colors, culture
- **Material Fidelity (2 points)**: Texture, weathering, Kintsugi
- **Cinematic Mood (2 points)**: Lighting, atmosphere, composition
- **Art Grammar (2 points)**: Ukiyo-e influence, Japanese aesthetics
