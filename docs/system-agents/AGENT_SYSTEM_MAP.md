# MIKAGE STUDIO AGENT SYSTEM MAP

## **System Overview**
12 specialized agents operating under MASTER SYSTEM PROMPT constitutional authority
- 1 orchestration layer
- 3 processing layers  
- 3 evaluation layers
- 2 support layers
- 1 audit layer
- 1 constitutional authority

## **Agent Classification**

### **Orchestration Layer**
1. **Chief Agent (Orchestration Director)** - System coordinator

### **Processing Pipeline**
2. **Brief Analyzer Agent** - Input structuring
3. **Prompt Compiler Agent** - Prompt construction
4. **Mode Director Agent** - Mode configuration
5. **Generation Controller Agent** - Asset generation

### **Evaluation Pipeline**
6. **Result Curator Agent** - Output preparation
7. **Reviewer Agent** - Quality evaluation
8. **Canon Gate Agent** - Canon validation

### **Support Layer**
9. **Aesthetic Analyst Agent** - Aesthetic intelligence
10. **Visual Knowledge Librarian** - Reference management

### **Archive Layer**
11. **Archivist Agent** - Data persistence

### **Audit Layer**
12. **QA Auditor Agent** - System integrity

### **Constitutional Authority**
- **MASTER SYSTEM PROMPT** - Constitutional governance

## **Pipeline Flow**

```
User Brief → Brief Analyzer → Prompt Compiler → Mode Director → 
Generation Controller → Result Curator → Reviewer → Canon Gate → Archivist
                    ↑                       ↑
      Aesthetic Analyst ← Visual Knowledge Librarian
                    ↓
                    QA Auditor (system-wide)
```

## **Authority Hierarchy**

1. **MASTER SYSTEM PROMPT** (constitutional)
2. **Chief Agent** (orchestration)
3. **Pipeline Agents** (processing/evaluation)
4. **Support Agents** (enrichment)
5. **Audit Agent** (verification)

## **Data Flow Dependencies**

- **Brief Analyzer** → Prompt Compiler (structured brief)
- **Prompt Compiler** → Mode Director (compiled prompt)
- **Mode Director** → Generation Controller (mode-configured prompt)
- **Generation Controller** → Result Curator (generated assets)
- **Result Curator** → Reviewer (review package)
- **Reviewer** → Canon Gate (review scores)
- **Canon Gate** → Archivist (canon decision)
- **Aesthetic Analyst** → Prompt Compiler (aesthetic suggestions)
- **Visual Knowledge Librarian** → Prompt Compiler (visual references)
- **QA Auditor** → All agents (audit reports)

## **System Boundaries**

- **Core Pipeline**: Agents 2-8 (brief → archive)
- **Support Services**: Agents 9-10 (enrichment only)
- **Governance**: Agent 1 + Master Prompt (authority)
- **Verification**: Agent 12 (integrity checking)

## **Integration Points**

- **Input**: Brief Analyzer (user entry point)
- **Output**: Archivist (final persistence)
- **Quality Gates**: Reviewer, Canon Gate
- **Authority Override**: Chief Agent, Master Prompt
- **System Monitoring**: QA Auditor
