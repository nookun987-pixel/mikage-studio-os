## Canon Integrity
- [ ] Character identity matches lore-core specifications
- [ ] Material usage follows canonical definitions
- [ ] Cultural elements remain authentic and appropriate
- [ ] No unauthorized lore additions or modifications

## Domain Integrity
- [ ] Scene domain correctly classified (imperial/neo_tokyo/transition)
- [ ] White Monolith protection enforced in imperial contexts
- [ ] Neo-Tokyo elements blocked from imperial environments
- [ ] Cross-domain contamination prevented

## Prompt Integrity
- [ ] All required prompt blocks present (subject, material, environment, cinematography, lighting, restriction)
- [ ] Forbidden elements properly excluded

- [ ] Negative constraints properly formatted

## Validation Integrity
- [ ] All validation checkpoints passed
- [ ] Hard fail conditions properly triggered when violated
- [ ] Revision requests generated for correctable issues
- [ ] Rejection issued for non-negotiable violations

## Critical System Checks
- [ ] Scene domain precedence properly applied
- [ ] White Monolith sterile porcelain identity maintained
