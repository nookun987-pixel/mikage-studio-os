## CANONICAL GROUPING RULES

### Primary Reference Assets
- **Core Canon**: Direct character representations, signature equipment
- **Supporting Canon**: Environmental elements, background assets
- **Contextual Reference**: Scene-specific elements, mood boards

### Secondary Reference Assets
- **Material Reference**: Surface textures, material properties
- **Lighting Reference**: Atmosphere, color temperature, light quality
- **Composition Reference**: Camera angles, framing, visual hierarchy

### Tertiary Reference Assets
- **Conceptual Reference**: Abstract ideas, mood boards, style guides
- **Technical Reference**: Engineering diagrams, system schematics
- **Cultural Reference**: Historical elements, cultural context

## ASSET CLASSIFICATION MATRIX

### By Canon Authority
- **core_canon**: Essential character identity, cannot be modified
- **supporting_canon**: Important world elements, limited modification
- **contextual_canon**: Scene-specific elements, flexible usage
- **reference_material**: Technical and artistic references, freely usable

### By Usage Scope
- **prompt_safe**: Can be used in automated generation prompts
- **character_only**: Restricted to character-specific contexts
- **environment_only**: Restricted to environmental contexts
- **reference_only**: For human reference and guidance only

### By Domain Association
- **imperial**: White Monolith, order, control, perfection
- **void_space**: ARCHON-IX, chaos, data, evolution
- **transition_zone**: Mixed domains, conflict, change
- **ritual_space**: Spiritual, ceremonial, traditional elements

## REFERENCE HIERARCHY

### Primary References (Highest Priority)
- Character identity assets (mask, core armor, signature weapons)
- Canon environment assets (key locations, architectural elements)
- Material reference assets (authentic surface textures)

### Secondary References (Medium Priority)
- Action pose assets (dynamic character positions)
- Environmental detail assets (specific location elements)
- Lighting reference assets (atmosphere and mood)

### Tertiary References (Lowest Priority)
- Concept art and mood boards
- Alternative interpretations
- Experimental or exploratory assets

## DUPLICATE HANDLING RULES

### Exact Duplicates
- Keep highest authority version
- Archive lower authority versions
- Maintain provenance chain

### Near Duplicates
- Preserve if they serve different purposes
- Tag with specific use cases
- Note differences in metadata

### Variants
- Maintain as separate assets if distinct
- Link to parent asset
- Document variant characteristics

## ASSET RELATIONSHIPS

### Parent-Child Relationships
- Armor components belong to armor sets
- Mask variants relate to base mask
- Weapon systems include sub-components

### Cross-Category Relationships
- Character assets link to associated armor/mask/weapon
- Environment assets contain architectural elements
- Material assets apply to multiple categories

### Temporal Relationships
- Assets may have evolution states
- Damage patterns show progression
- Historical context tracked in metadata
