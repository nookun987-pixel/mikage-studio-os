# MIKAGE VISUAL AUTHORITY MAP

## **1. Aesthetic Philosophy**

### **Source Files**
- `Japanese Visual Aesthetics AI Knowledge Packs.md`
- `01_aesthetic_philosophy/aesthetic_philosophy.library.json`

### **Extracted Visual Rules**
- **Wabi-Sabi**: Beauty in imperfection, fractured elegance, weathered ceramic
- **Ma (間)**: Intentional negative space, visual silence, controlled breathing room
- **Notan (濃淡)**: Binary light-dark balance, high-contrast silhouettes
- **Ki-sho-ten-ketsu**: 4-act narrative pacing, rhythmic layout
- **Oku (奥)**: Spatial inwardness, layered foregrounds, peeking frames

### **Symbolic Meaning**
- **Fracture**: Identity through imperfection, not flaw
- **Silence**: Active design element, not empty void
- **Balance**: Binary mass equilibrium, not gradient modeling
- **Rhythm**: Narrative pacing through visual structure

### **Usage Guidance for Generative Prompts**
```
wabi_sabi, fractured elegance, imperfect beauty, weathered ceramic
ma, negative space, visual silence, minimal Japanese composition
notan, binary mass balance, high-contrast silhouette
ki_sho_ten_ketsu, cinematic narrative turn, rhythmic layout
oku, framed through doorway, foreground occlusion
```
