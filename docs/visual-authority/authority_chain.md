# VISUAL AUTHORITY CHAIN

## **Authority Hierarchy**

```
Japanese Aesthetic Philosophy (Level 1)
    ↓
Historical Visual Grammar (Level 2)
    ↓
Motif System + Color + Line Systems (Level 3)
    ↓
Folklore Symbolics + Modern Evolution (Level 4)
    ↓
Neo Tokyo Futurism (Level 5)
    ↓
Mikage Application Layer (Level 6)
```

---

## **Level 1: Japanese Aesthetic Philosophy**

**Authority**: CONSTITUTIONAL
**Scope**: Foundational visual principles
**Override Power**: Can override all lower levels
**Responsibility**: Core aesthetic truth

### **Core Principles**
- **Wabi-Sabi**: Beauty in imperfection and transience
- **Ma (間)**: Intentional negative space as active design element
- **Notan (濃淡)**: Binary light-dark balance and mass equilibrium
- **Ki-sho-ten-ketsu**: 4-act narrative structure and rhythmic pacing
- **Oku (奥)**: Spatial inwardness and layered depth

### **Authority Rules**
- All visual decisions must respect these principles
- No lower level can contradict philosophical foundations
- These principles are non-negotiable for Mikage IP

---

## **Level 2: Historical Visual Grammar**

**Authority**: HISTORICAL
**Scope**: Edo/Medieval visual language
**Override Power**: Can override Levels 3-6
**Responsibility**: Cultural authenticity

### **Core Grammar**
- **Flat Perspective**: Layered planes, compressed depth
- **Bold Outline**: Strong contour lines, silhouette authority
- **Color Blocks**: Flat chroma zones, disciplined palette
- **Diagonal Composition**: Directional flow, asymmetric force
- **Poster Framing**: Hero-first composition, clear hierarchy
- **Kabuki Pose**: Theatrical posture, expressive stillness
- **Dramatic Gesture**: Symbolic hand and limb articulation
- **Stage Framing**: Symbolic tableau, frontal read

### **Authority Rules**
- Must respect Level 1 philosophical principles
- Provides cultural foundation for all modern adaptations
- Cannot be contradicted by modern interpretations

---

## **Level 3: Applied Systems**

**Authority**: SYSTEMATIC
**Scope**: Structured visual systems
**Override Power**: Can override Levels 4-6
**Responsibility**: Consistent application

### **3.1 Motif System**
- **Nature Motifs**: Sakura, Koi, Crane, Maple, Bamboo
- **Supernatural Motifs**: Dragon, Kitsune, Oni, Tengu, Kappa
- **Pattern Motifs**: Seigaiha Wave, Cloud transitions
- **Intensity Levels**: Low, Medium, High with mode restrictions

### **3.2 Color System**
- **Traditional Colors**: Aka (red), Ao (blue), Shiro (white), Kuro (black)
- **Mineral Pigments**: Gunjo (blue), Shu (vermilion), Enji (carmine)
- **Mikage Palettes**: Porcelain Canon, Neon Ma, Yokai Signal
- **Application Rules**: Mode-specific color restrictions

### **3.3 Line System**
- **Ink Confidence**: Bold, deliberate strokes with authority
- **Brush Pressure**: Variable weight showing intention
- **Calligraphy Structure**: Balanced composition within bounds
- **Modern Adaptations**: Cel shading, anime line weights

### **Authority Rules**
- Must respect Levels 1-2 foundations
- Provide systematic application of higher principles
- Cannot contradict philosophical or historical rules

## **Conflict Resolution Protocol**

### **Step 1: Check Authority Level**
Higher authority always wins over lower authority

### **Step 2: Check Domain Compatibility**
Different domains can coexist if they don't directly conflict

### **Step 3: Check Application Context**
Context-specific rules can apply within their domain

### **Step 4: Escalate if Needed**
Unresolved conflicts escalate to higher authority level

## **Authority Enforcement**

### **Constitutional Authority (Level 1)**
- Cannot be overridden
- Must be preserved in all visual decisions
- Violations result in automatic rejection

### **Historical Authority (Level 2)**
- Can only be overridden by Level 1
- Must be preserved for cultural authenticity
- Violations require special justification

### **System Authority (Level 3)**
- Can be overridden by Levels 1-2
- Provides consistency across applications
- Violations result in quality warnings

### **Evolution Authority (Level 4-5)**
- Can be overridden by Levels 1-3
- Provides modern relevance
- Violations result in review requirements

### **Application Authority (Level 6)**
- Can be overridden by all higher levels
- Provides IP-specific identity
- Violations result in IP drift warnings
