## Neo-Tokyo Visual Authority

`neo_tokyo_reference_index.json` is the canonical visual authority file for Neo-Tokyo-related style language and boundary enforcement. It contains both visual style authority and governance/compliance/enforcement layers.

### Imperial Environment Precedence

Neo-Tokyo density, rain neon, signage, and alley logic must never automatically override porcelain-clean imperial environments such as White Monolith. White Monolith, upper imperial zones, sterile porcelain minimalism, and absolute-order environments always take precedence over Neo-Tokyo clutter logic when scene classification is imperial.
