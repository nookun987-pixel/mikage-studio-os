# Mikage Japanese Core

## Inherit from Japanese philosophy
- wabi_sabi: fracture, porcelain, imperfect luxury.
- ma: emptiness, silence, isolation, negative space.
- mono_no_aware: transient melancholy and fragile stillness.

## Inherit from traditional grammar
- poster framing
- elegant asymmetry
- strong silhouette
- quiet dramatic pose
- limited palette discipline

## Mikage must not become
- generic neon cyberpunk girl
- random samurai anime clone
- yokai fantasy without system logic
- overdecorated japan-core collage
- blade-runner copy with japanese stickers

## Allowed reinterpretation zones
- porcelain armor
- ritual tech
- shrine-like interfaces
- silent vertical city
- ceremonial silhouettes
- fractured luxury futurism
