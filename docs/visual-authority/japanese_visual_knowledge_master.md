# Japanese Visual Knowledge Master

## Purpose
Structured art direction intelligence for Mikage / Tokyo Future, designed for direct studio use in references, presets, compile flow, motif tagging, and color mode selection.

## Core Libraries
- Aesthetic Philosophy: wabi_sabi, ma, mono_no_aware
- Edo Visual Grammar: flat_perspective, bold_outline, color_blocks, diagonal_composition, poster_framing, kabuki_pose, dramatic_gesture, stage_framing
- Motif Library: sakura, koi, crane, dragon, seigaiha_wave, cloud, maple_leaf, bamboo, kitsune, oni
- Color System: ukiyoe_classic_palette, indigo_red_ink, parchment_ink, moss_ochre, porcelain_neon_tokyo
- Folklore / Yokai: kitsune, tengu, oni, yuki_onna, tanuki, yokai_parade, spirit_animals
- Neo Tokyo Futurism: neo_tokyo_density, rain_neon_alley, vertical_signage, cyber_shrine, porcelain_tech, ritual_interface, silent_megacity

## Mikage Application
- Inherit wabi_sabi through fracture and porcelain.
- Inherit ma through silence and negative space.
- Inherit mono_no_aware through transient melancholy.
- Keep poster framing, elegant asymmetry, strong silhouette, quiet dramatic pose, limited palette discipline.
- Reject generic cyberpunk drift and anime clone behavior.
